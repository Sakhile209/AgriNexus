# AgriNexus User Stories

## Farmer
- As a farmer, I want to register my farm so that I can manage my operations digitally.
- As a farmer, I want to record livestock health so that I can reduce animal losses.
- As a farmer, I want to receive vaccination reminders so that I can keep animals healthy.
- As a farmer, I want to track crops so that I can improve productivity.
- As a farmer, I want to view market prices so that I can make better selling decisions.

## Cooperative
- As a cooperative manager, I want to manage member farmers so that I can coordinate production.
- As a cooperative manager, I want to review reports so that I can monitor performance.

## Government
- As a government officer, I want to view regional dashboards so that I can monitor agriculture conditions.
- As a government officer, I want to track disease alerts so that I can respond quickly.

## Supplier
- As a supplier, I want to list products so that I can reach more buyers.
- As a supplier, I want to monitor advertising performance so that I can improve visibility.

## Buyer and Consumer
- As a buyer, I want to browse products so that I can source quality goods efficiently.
- As a consumer, I want to purchase locally so that I can support nearby farmers.
